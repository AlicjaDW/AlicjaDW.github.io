# alicjadw.github.io

Portfolio of Alicja Walaszek: customer insight and commercial analytics.

- `index.html`: home page (work, about, experience, contact)
- `work/`: one page per case study
- `dashboards/`: live dashboards rebuilt with fictional sample data
- `assets/`: stylesheet, screenshots and the LinkedIn preview image (`assets/img/og-image.png`)

Hosted free on GitHub Pages. Edit any page in GitHub and the site updates within a minute or two.
